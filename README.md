Personal portfolio — React + Vite + MUI + Tailwind. (Yes, the first draft of this README said "hahaha". Standards have improved.)

## ▚ Run it

```bash
npm i
npm run dev     # dev server
npm run build   # production build (vite build)
npm run server  # express server (server.js)
```

## ▚ Stack

React 18 · Vite 6 · MUI + Radix primitives · Tailwind 4 · Recharts · Motion
